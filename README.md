# GlideCoilPicassoRoom

Android-песочница для знакомства с библиотеками загрузки изображений
(Glide, Coil, Picasso) и базой данных Room. Всё собрано в одной `MainActivity`.

## Что внутри

- **Room** (активный код): сущность `Cat`, DAO с выборками (все записи, имена,
  поиск по имени, диапазон и список возрастов), база `cat_db`. При запуске
  в фоновом потоке в базу пишутся тестовые записи, результат выборки выводится в лог;
  в коде также есть пример миграции `1 → 2` (добавление колонки).
- **Glide, Coil, Picasso** — примеры загрузки картинки и GIF в `ImageView`
  с трансформациями (crossfade, скругление, обрезка по кругу, grayscale).
  Оставлены закомментированными: для проверки нужной библиотеки раскомментируйте
  её блок в `MainActivity`.

## Стек

| Область     | Технологии                |
|-------------|---------------------------|
| Язык        | Kotlin                    |
| Изображения | Glide, Coil (+ coil-gif), Picasso |
| Хранение    | Room (схема экспортируется в `app/schemas`) |
| UI          | ViewBinding               |

## Сборка

Требуется JDK 11–17 и Android SDK 31.

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
